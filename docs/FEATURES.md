# Возможности — AiSaray Mail (Email_server + DirectMail)

AiSaray Mail — единый почтовый продукт: корпоративные ящики и встроенный модуль массовых рассылок DirectMail. Ниже — пользовательский функционал без инфраструктурных рецептов.

## Роли и что видит каждая

### Сотрудник / владелец ящика
Входит в веб-почту, читает и пишет письма, работает с папками, вложениями, поиском, фильтрами и автоответом. Может подключить ящик в Outlook, Thunderbird или на телефоне по IMAP.

### Маркетолог / оператор рассылок
Работает в кабинете DirectMail: кампании, шаблоны, контакты, сегменты, preflight, запуск, пауза, статистика доставок и отказов.

### Администратор платформы
Управляет доменами и ящиками (создание, пароли, квоты, активность), настраивает переадресацию с фильтрами, контролирует DNS-подсказки для доменов и общий порядок отправок.

### Владелец бизнеса
Оценивает, что почта и рассылки живут на своём домене, видит комплектацию «под ключ» и понятный кабинет без сборки стека с нуля.

## Функциональные блоки

### Корпоративная почта на своём домене
Пользователь получает адреса вида `имя@ваш-домен.ru`, а не «ящик на чужом сервисе». Несколько доменов и проектов могут жить на одной платформе.

- Ящики для сотрудников и отделов
- Веб-интерфейс на русском языке
- Доступ с телефона и десктоп-клиентов (IMAP)
- Папки, вложения, поиск по почте
- Фильтры и автоответ
- Несколько доменов на одном сервере

### Веб-кабинет (вход)
Единая точка входа на https://mail.aisaray.ru/: корпоративный ящик или кабинет DirectMail.

- Форма входа по email и паролю ящика
- Переход с лендинга «Войти в кабинет»
- Работа через браузер без установки серверного ПО пользователем

### Управление ящиками
Администратор создаёт и ведёт ящики через веб, без ручной возни «для каждого сотрудника отдельно на сервере».

- Список ящиков: email, домен, квота, статус
- Добавление пользователя (email, пароль, квота, активность)
- Смена пароля и квоты
- Отключение / удаление ящика
- Проверка, что домен уже подключён к платформе

### Переадресация с фильтрами
Входящие можно пересылать на другой адрес по правилам: тема, отправитель, домен отправителя, комбинации условий.

- Правила переадресации на выбранный ящик
- Фильтры по заголовкам (тема, From, To и др.)
- Фильтры по email / домену отправителя
- Операторы: содержит, равно, начинается с, заканчивается на
- Включение / выключение правила без удаления
- Письмо остаётся под контролем политики ящика (не «тихий угон» почты)

### DirectMail — кампании
Модуль рассылок встроен в тот же сервер: не нужна отдельная подписка на «чужой ESP» только ради HTML-писем.

- Создание кампании: тема, HTML, отправитель `offer@домен`
- Выбор базы или сегмента
- Тестовое письмо до массового запуска
- Планировщик и пауза
- Лимиты скорости (постепенная отправка)
- Статусы кампании и контроль хода

### Адресная книга и импорт
Единый справочник контактов для рассылок.

- Email, имя, категория, город и др. поля карточки
- Импорт Excel / CSV
- Экспорт выборок
- Сегменты и фильтры («живые», проблемные, ещё не слали)
- Добавление в кампанию из справочника

### Preflight и проверка адресов
Перед стартом видно, сколько адресов готово, сколько в проверке, сколько будет исключено.

- Проверка синтаксиса адреса
- Проверка MX / доставляемости на уровне сервиса проверки
- Исключение заведомо плохих адресов до массовой волны
- Снижение риска «сжечь» репутацию домена пустой/мусорной базой

### Доставляемость и защита репутации
Система рассчитана не на «вылить 50 000 за час», а на контролируемую отправку.

- DKIM-подпись, SPF, DMARC для домена
- Постепенная отправка с паузами и суточными лимитами
- Авто-стоп при росте hard bounce и жалоб
- List-Unsubscribe / отписка one-click в письмах
- Изолированная обработка отказов (bounce)

### Аналитика рассылок
Оператор видит не только «кнопку Отправить», но и последствия.

- Отправлено / доставлено / bounce
- Воронка кампании
- История и timeline по получателю
- Разбор отказов hard / soft
- Опора для решения: продолжать, чистить базу, менять сегмент

### Домены и DNS для пользователя
Подключение домена сопровождается понятными записями для регистратора (MX и записи доставляемости).

- Несколько доменов на одной платформе
- Отдельные ящики и отправители по доменам
- Готовые подсказки DNS для копирования у регистратора
- Модель «бренд / проект = свой домен» без отдельного сервера на каждый сайт

### Безопасность для пользователя
На уровне результата: шифрование при передаче, антиспам на входящих, защита от подбора пароля, аудит критичных действий со статусами получателей.

- TLS при доступе к почте и отправке
- Антиспам на входящем потоке
- Защита от брутфорса входа
- Контроль аномалий рассылки (авто-стоп)
- Разделение повседневной почты и служебных bounce-потоков

## Сквозные пользовательские потоки

### Подключение компании
1. Оставить заявку или получить доступ к серверу  
2. Подключить домен (DNS по подсказкам)  
3. Создать ящики сотрудников  
4. Войти в веб-почту и проверить отправку/приём  
5. При необходимости открыть DirectMail и сделать тестовую кампанию  

### Запуск рассылки маркетологом
1. Войти в кабинет  
2. Создать кампанию и письмо  
3. Загрузить базу или выбрать сегмент  
4. Запустить проверку (preflight)  
5. Отправить тест себе  
6. Запустить кампанию и смотреть статистику / bounce  

### Админ: новый сотрудник
1. Открыть управление ящиками  
2. Создать `имя@домен` с квотой  
3. Выдать пароль сотруднику  
4. При необходимости настроить переадресацию/фильтры  
5. Сотрудник входит с веба или телефона  

## Чем продукт НЕ является

- Не «ещё один бесплатный ящик на чужом домене»
- Не анонимный спам-сервис без контроля отказов
- Не отдельный SaaS только для рассылок без своей почты (здесь почта и DirectMail связаны)
- Не публикация исходников Postfix/плагинов в этом GitHub-репозитории

## Словарь терминов

- **AiSaray Mail** — публичное имя продукта на mail.aisaray.ru  
- **Email_server** — имя контура/репозитория документации продукта  
- **DirectMail** — встроенный модуль массовых рассылок  
- **Preflight** — проверка базы до массовой отправки  
- **Bounce** — отказ в приёме письма (hard/soft)  
- **DKIM / SPF / DMARC** — DNS-механизмы доставляемости и защиты домена  
- **Квота** — лимит объёма ящика  

## Ограничения публичной документации

- Без исходников, секретов, ENV, паролей и дампов контактов  
- Без пошаговых инфраструктурных рецептов администрирования сервера  
- Фокус: что умеет продукт для человека-пользователя и покупателя сервера
