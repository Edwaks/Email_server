# Сценарии использования — AiSaray Mail

Типовые пользовательские сценарии без технических деталей внедрения.

## 1. Корпоративная почта для отдела продаж

**Контекст:** Компании нужны ящики `sales@`, `manager@` на своём домене.

**Шаги:**
1. Подключить домен по DNS-подсказкам платформы  
2. Создать ящики с квотами  
3. Выдать доступы сотрудникам  
4. Сотрудники входят в веб или настраивают телефон  
5. При необходимости настроить переадресацию секретарю / CRM-ящику  

**Результат:** Почта команды работает под брендом компании.

## 2. Первая маркетинговая рассылка

**Контекст:** Есть Excel с клиентами и HTML-шаблон акции.

**Шаги:**
1. Войти в кабинет DirectMail  
2. Создать кампанию и письмо  
3. Импортировать базу  
4. Запустить preflight  
5. Отправить тест себе  
6. Запустить кампанию и смотреть доставки/bounce  

**Результат:** Контролируемая рассылка с понятной статистикой.

## 3. B2B-охват с защитой домена

**Контекст:** Большая холодная база, риск hard bounce.

**Шаги:**
1. Загрузить базу  
2. Дождаться/просмотреть результаты проверки адресов  
3. Исключить мусорный сегмент  
4. Запустить волну с лимитами  
5. Следить за авто-стопом и жалобами  
6. Не слать повторно на «мёртвые» адреса  

**Результат:** Охват без бездумного сожжения репутации домена.

## 4. Несколько брендов на одном сервере

**Контекст:** Агентство или группа компаний с разными доменами.

**Шаги:**
1. Подключить домены проектов  
2. Создать отдельные ящики и отправителей  
3. Вести кампании раздельно по брендам  
4. Смотреть статистику в разрезе кампаний/доменов  

**Результат:** Один сервер — много проектов без путаницы ящиков.

## 5. Переадресация входящих руководителю

**Контекст:** Нужно дублировать письма с `info@` на личный ящик с фильтром по теме.

**Шаги:**
1. Администратор открывает переадресацию  
2. Выбирает ящик `info@`  
3. Создаёт правило: тема содержит «Счёт» → переслать на нужный адрес  
4. Включает правило  
5. Проверяет тестовым письмом  

**Результат:** Нужные письма доходят по правилу, остальной поток не шумит.
